# 灵迈 Logo

当前版本采用纯黑单色方案，以一条连续路径变形出小写感的 `M`：两侧是稳定的处理边界，中间下探的折点代表材料汇集后形成清晰判断。

- `linkmai-mark.svg`：独立字母标，适合小程序头像、启动页、favicon 和印刷。
- `linkmai-lockup.svg`：字母标 +「灵迈」中文名 + LINKMAI 英文名，适合页面头部、宣传物料和品牌介绍。

## 使用规则

- 首选黑色 `#000000`，置于白色或浅色背景；深色背景使用白色反相显示。
- 小尺寸优先使用独立字母标，避免中文名在 64px 以下变得难以辨认。
- 四周至少保留图形笔画宽度两倍的安全空间。
- 不改变笔画比例、不拆分路径、不添加描边、阴影或渐变。
