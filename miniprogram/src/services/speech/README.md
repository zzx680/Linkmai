# 口述经过：语音转文字

使用腾讯官方「微信同声传译」插件（`WechatSI`，provider `wx069ba97219f66d99`），不需要后端密钥或新增上传接口。只将最终文字追加到输入框，用户修改、确认后主动发送，聊天不会产生语音消息。H5 预览不调用浏览器语音服务，提示在微信小程序使用。

## 插件状态与编译

2026-10-19 用户提供的后台截图已确认「微信同声传译」状态为「已通过」，详情链接的 provider 与配置一致。普通开发、生产构建默认启用，无需每次额外设置开关。插件授权通过不代表平台隐私声明或真机识别已验收。

1. 当前项目 AppID 为 `wx38fafb051a96a529`。若更换小程序账号，先在对应后台添加并授权上述插件；未授权账号应使用下方关闭开关编译。
2. 在平台「用户隐私保护指引」中按实际用途声明麦克风 / 录音信息用于语音转文字，核对插件隐私说明。本地隐私页已补充采集目的、处理方及使用选择，单独征求同意，拒绝不影响键盘输入。
3. `config/voice-input.ts` 目前固定官方开源示例使用的 `0.3.3`。确认后台允许此版本；若平台要求其他版本，先更新配置并重新验收，不使用未经验证的版本号。
4. 从仓库根目录编译：

```bash
TARO_APP_API_BASE=https://api.linkmai.com/api npm --prefix miniprogram run build:weapp
```

构建会同时开启运行开关，在 `app.json` 声明插件及 `scope.record`。需要关闭时设置 `TARO_APP_VOICE_INPUT_ENABLED=false` 后重新编译，按钮点击会提示暂不可用并保留草稿；不要只改 app.json 或只改运行开关。编译产物默认写入开发者工具读取的 `dist/`，本地构建不会自动上传或发布。

官方依据：[插件文档](https://mp.weixin.qq.com/wxopen/plugindevdoc?appid=wx069ba97219f66d99&lang=zh_CN)、[腾讯面对面翻译示例](https://github.com/Tencent/Face2FaceTranslator)。

## 行为与验收

- 点击「口述经过」→ 单独同意语音处理和麦克风授权 → 开始说话 →「说完了」→ 最终文字追加到原草稿，不自动发送
- 最长 60 秒；部分识别结果只展示在口述状态卡中，最终结果以插件 `onStop.result` 为准
- 取消、页面隐藏、退出登录或切换案件会停止采集，忽略迟到结果，防止文字进入其他案件
- 全局唯一识别管理器在旧任务结束前禁止复用；没有收到结束事件时保持隔离，不假装可以继续识别
- 不向灵迈后端上传音频，插件返回临时音频路径时尝试删除；插件自身处理规则以平台说明为准
- 不在日志中记录口述音频或识别文本

本地单元检查覆盖转写、静音、拒绝、取消竞态、草稿保留和发送隔离。构建通过不代表插件已开通或声音已真实识别。

发布前需在 iOS / Android 真机验证：首次授权和拒绝、设置中恢复权限、口述后文字核对、取消不追加、断网与识别失败、60 秒结束、后台切换 / 退出登录 / 切换案件、已有草稿不覆盖，以及键盘与底部导航不遮挡。微信开发者工具只能辅助检查，不能代替真实麦克风验收。
