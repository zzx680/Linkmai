## SSH 检查结果和配置位置

用户提供：阿里云轻量应用服务器，Ubuntu 22.04，`114.55.96.52`，云端密钥名称 `linkmai-deploy`。

- 本机 `~/.ssh`、下载和文档目录中未找到名称匹配 `linkmai-deploy` 的私钥；这不等于能证明私钥在本机所有位置均不存在。
- 本机存在 `~/.ssh/id_ed25519` 及其公钥，但尚未验证它是否对应云端这把密钥。云端密钥名称无需等于本地文件名。
- 没有 `~/.ssh/config`，未发现该服务器的 SSH 主机别名配置。本次没有修改 SSH 配置，也没有读取或展示私钥内容。

下一步在**阿里云轻量应用服务器控制台 → SSH 密钥/密钥对管理**中查看 `linkmai-deploy` 的绑定实例和公钥/指纹，并在实例的登录说明中确认实际 SSH 用户名；不要根据 Ubuntu 版本猜成 `root` 或 `ubuntu`。

可用以下本机命令显示已有公钥的指纹，再与云端信息核对（不输出私钥）：

```sh
ssh-keygen -lf ~/.ssh/id_ed25519.pub
```

**仅在确认已有密钥匹配后**，在本机 `~/.ssh/config` 配置：

```sshconfig
Host linkmai-production
  HostName 114.55.96.52
  User <控制台确认的登录用户名>
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes
```

若找到了最初下载的对应私钥，可将它存放为 `~/.ssh/linkmai-deploy`，设置私钥权限为 `600`，并将上面的 `IdentityFile` 改为该路径。`~/.ssh` 目录建议 `700`，`~/.ssh/config` 建议 `600`。不要发送密码或私钥。

如果对应私钥已经丢失，阿里云不能重新提供该私钥。需要另行安排新建/导入公钥并绑定实例；这会涉及服务器配置变化，应作为后续操作单独处理，本次未进行。
